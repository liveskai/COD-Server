COD14《使命召唤：二战》武器 · 配件 数据总览 只读数据，非模组

数据源：statstable.csv（武器 8 项数值）· attachmenttable.csv（配件六槽数值）· attachmentcombos_mtx12.csv（互斥矩阵）· s1cacutils / _class.gsc（武器与配件白名单）

附录 A · 数值列语义（已交叉验证）

statstable 武器行 col10..17 依次为 精度 / 伤害 / 射程 / 射速 / 机动 / 操控 / 备弹 / 弹匣。
决定性证据：statstable 中 197 行 col0 == weapon_attachment 行，其 6 个数值列与 attachmenttable.csv 的 r9..r14 逐条同序同值， 而后者语义为 [Accuracy, Damage, Range, FireRate, Mobility, Handling]：
  • grip → col10 = +3（精度）
  • fmj / head_damage → col11 = +3（伤害）
  • extended_range → col12 = +3（射程）　rapid_fire → col13 = +3（射速）
  • akimbo → col14 = +3（机动）　　fast_ads → col15 = +3（操控）
  • suppressor → col11 = −3（伤害）
旁证：ptrs41 / panzerschreck / springfield / blunderbuss 的 col11 = 10（伤害满值）， kar98 / mosin / sdk 的 col13 = 1（栓动最低射速）。

附录 B · 游戏内 CAC 面板只显示 5 项

由 ui/s2/cac_stats_pane.lua 可读出，配枪界面实际只有 5 条： DamageBar、AccuracyBar、RangeBar、FireRateBar、 以及 Capacity（弹匣/备弹，形如 42/126）。 机动（mobility）与操控（handling）在界面上不显示，属于内部属性 —— 本报告把它们单独标出（灰色 + ·）。

附录 C · 按武器大类的硬性配件排除规则

出自 _division_change.gsc::func_56CA（武器族级硬排除，优先级高于白名单）：
  • weapon_shotgun → 排除含 dragon_breath_ 的配件
  • weapon_heavy（轻机枪）→ 排除含 bipod 的配件
  • weapon_assault（步枪）→ 排除含 bayonet_、grenade_launcher 的配件
  • weapon_smg → 排除含 suppressor_ 的配件
  • weapon_sniper → 排除含 hold_breath 的配件
  • weapon_pistol → 排除含 tacticalknife 的配件（原始代码此处无下划线）
另在 gun.gsc::getattachmentsforweapon() 中还有一层互斥时的实时剔除： 已装瞄具则剔除 iron_sight / telescopic_sight / lens_sight / aperture_sight； 与 special_grip / akimbo / m30_rifle / tactical_knife / suppressor / bipod / hold_breath / extended_mag / bayonet / grenade_launcher 冲突的会被移除。

附录 D · 数据缺口

rpd（RPD）、type99（Type 99）、kbsp1938（Karabin 1938M） 在当前 dump 的 statstable.csv 里没有武器本体行（只存在它们的专属配件行）， 因此数值空缺。这三把属于 DLC/开箱形态，武器 def 在未解包的 zone 内。
另：大量 DLC 枪的 机动 / 操控 为 0，表示未单独配置、走引擎默认值，并非真的「0」。 近战武器与 bazooka / panzerschreck 无配件（发射器只有瞄具槽）。
